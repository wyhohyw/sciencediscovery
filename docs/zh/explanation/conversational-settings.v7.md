# 对话内按需配置 · 无人值守接续与低风险自动应用 v7

本版接续[明确连接器指令 v6](conversational-settings.v6.md)和[开发文档 v1 第 9 节](conversational-settings-development.v1.md)。当前连接器切片在 Agent 提议后结束运行；用户确认只保存配置，原任务不会自动接续。对长任务，这是不可接受的停止点。

## 目标行为

1. Agent 在任务中提出配置请求后，于已完成工具批次的安全边界交回控制权。卡片显示任务在等待配置，不占用活跃运行资源，也不把该任务标记为正常完成。
2. 用户确认后，系统自动创建**同一任务的关联后续运行**；沿用原目标、已完成动作和产物，使用新配置。用户无需再输入“继续”。纯粹的显式配置指令没有研究任务，不生成空的后续运行。
3. 用户拒绝时，不写配置。Agent 只有确实存在安全替代路径才可继续；否则任务标记为需要用户处理。Stop、归档和删除优先于接续。
4. 接续创建和调度必须持久、幂等。刷新、双击确认、服务重启、并发确认不会产生第二个后续运行；无法证明外部副作用结果时，不自动重放。

## 低风险自动应用

「始终允许」目前只授权工具调用，**不授权配置变更**。新增独立、默认关闭的“自动应用低风险会话配置”授权。界面明确展示能力白名单、仅当前会话生效、30 秒撤销缓冲期和关闭入口；授权变更记录在审计中。

首批仅允许经过逐项审查的、已安装且就绪、无需凭据或付费、不会更改全局/项目设置的公开只读连接器。连接器属于白名单仍须在应用时复核安装状态、当前会话授权、配置基线和任务/Stop 状态。新增连接器默认不在白名单；模型连接、凭据、OAuth、代理、远程执行及全局/项目设置始终要求用户确认。

符合条件的提案显示 30 秒倒计时与“取消”按钮。30 秒是事先授权后的撤销机会，不是授权本身。到期后服务端应用配置并自动接续任务；用户离线、浏览器关闭或服务重启不影响已授权的决定。授权在倒计时期间关闭则请求回到人工确认。到期时任何前置条件不满足则停止自动应用并明确提示，不能放宽范围或静默改用其他设置。

## 验收

- 普通连接器请求：任务中出现卡片；确认后只产生一个关联后续运行，已完成步骤不重复执行，配置在后续运行生效。
- 纯配置指令：确认后生效但不启动无目标任务。
- 独立授权关闭时，30 秒后仍等待人工确认；「始终允许」不改变这个结果。
- 独立授权开启且连接器在白名单时，倒计时内可取消；到期自动应用并接续。关闭授权、Stop、基线变化和连接器失效都阻止自动应用。
- 浏览器刷新、重复确认和服务重启不重复配置提交或接续。
