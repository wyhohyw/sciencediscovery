# 对话内按需配置 · 确认后的简洁回执 v8

本版接续[无人值守接续与低风险自动应用 v7](conversational-settings.v7.md)，只调整配置请求的对话呈现，不改变配置或工具权限规则。

## 确认后的呈现

- 待确认时保留完整配置卡，说明变更、作用域和确认操作。
- 人工确认或低风险自动应用后，完整卡立即消失。对话只保留一行包含连接器名称和会话作用域的结果，例如“PubMed 已启用 · 仅当前会话”。
- 关联接续运行的结果行显示在源运行与后续运行之间；不得再在对话底部重复一张已应用卡。纯配置指令没有后续运行时，在原卡位置保留同样的一行结果。
- 等待工具权限属于独立的运行状态，继续由权限卡显示；配置结果行不声称任务一直在运行，也不代替工具权限审批。
- 刷新页面后，从持久请求和运行记录恢复相同的呈现；拒绝或失效的请求不再保留可操作的完整配置卡。
