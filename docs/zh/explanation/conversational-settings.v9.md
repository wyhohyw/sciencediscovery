# 对话内按需配置 · 可展开的配置回执 v9

本版接续[确认后的简洁回执 v8](conversational-settings.v8.md)，沿用原有配置、接续与工具权限规则，只调整已处理请求的呈现。

## 已处理请求的折叠记录

- 待确认的配置请求继续显示完整卡片和操作按钮。确认、自动应用或失效后，不再显示可操作的完整卡片。
- 已启用结果默认折叠为与 Agent 活动记录一致的一行，例如“PubMed 已启用 · 仅当前会话”。点击或键盘操作可展开，再次操作可收起；展开内容只读，说明连接器、作用范围和任务接续情况，不重复确认按钮。
- 对有研究任务的请求，折叠记录位于源运行与关联后续运行之间。对纯配置指令，在原卡位置保留同样的折叠记录。持久请求与运行记录在刷新后恢复相同状态，并避免出现两份回执。
- 失效请求也用只读折叠记录说明没有修改配置。工具调用权限仍由独立权限卡控制，配置回执不暗示工具已获授权。
