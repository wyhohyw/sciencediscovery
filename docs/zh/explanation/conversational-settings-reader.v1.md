# 对话配置文档 · 连续阅读规格 v1

- 日期：2026-10-19。
- 适用：`conversational-settings.html` 阅读页 v4；产品设计 v11 和完整开发文档 v4 的内容版本不变。
- 原阅读页 v3 保留在 Git 提交 `208a4d0f`，本规格记录新的阅读交互，不改变产品配置功能。

## 连续正文

1. WEB-RD01：总览、完整设计、完整开发文档、当前实测在同一页面按顺序连续展示。全部章节在构建时写入 HTML，向下滚动即可读完，不需要“上一章/下一章”，也不通过替换正文模拟单页。
2. WEB-RD02：每份文档只出现一次完整标题、版本和说明，每章有独立标题与稳定锚点。现有章节和小节 hash 链接继续有效；点击目录、搜索或正文链接滚到目标，不移除其他章节。
3. WEB-RD03：历史文档在正文中默认折叠。点击其目录锚点先展开对应历史文档再定位；闭合历史内容不参与当前章节计算。

## 目录与位置

1. WEB-RD04：左侧目录以视口顶部固定栏下方的阅读线判断当前章节，滚动时自动高亮。章间空隙保留上一章；文档末尾不足一屏时仍能高亮最后一章；总览区域高亮总览。
2. WEB-RD05：跨文档阅读自动展开对应目录组。只滚动左侧目录自身来保持选中项可见，不移动正文、不抢焦点。移动端目录可关闭，滚动仍更新当前章节。
3. WEB-RD06：面包屑、右侧本章小节目录、复制章节链接与下载当前文档随当前章节更新。滚动更新 URL 使用 replaceState，不为每章堆积浏览器历史；显式目录跳转保留正常前进/后退。
4. WEB-RD07：跳转、滚动、窗口变化或展开历史时，目录应及时更新。正文读取不依赖外部网络资源；无脚本时仍可阅读连续正文。

## 验证

- 构建后检查每个章节/小节锚点唯一且正文完整、无分页控件、主正文未隐藏。
- 测试阅读线选择、总览、章间空隙、最后短章、默认闭合历史及无可见正文。
- 检查脚本语法、源内容 hash、链接和两个本地阅读路径的构建一致性。
- 浏览器视觉验证单独记录；代码和静态结构检查不能代替已完成浏览器验证的声明。
