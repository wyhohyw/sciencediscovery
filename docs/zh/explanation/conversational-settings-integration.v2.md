# 对话内配置：首个真实接入切片 v2

本版基于 [接入切片 v1](conversational-settings-integration.v1.md) 和 [交互设计 v2](conversational-settings.v2.md)，修正无模型时配置卡过早出现的问题。接入范围仍限于缺少当前会话任务模型的情形。

## 已接入的流程

1. 打开没有任务模型的会话时，显示普通输入区和模型选择器，不主动展示配置卡或第二条配置入口。
2. 用户输入非空任务并按 Enter 或点击“配置并继续”时，前端暂停运行提交，保留草稿，在对话中展示一张配置卡。再次提交时复用当前卡片，不产生额外聊天消息或运行。
3. 选择已有模型或在卡片内连接新模型，确认后只绑定当前会话，并通过正常提交路径继续发送草稿。新建资源不自动改变全局默认模型；凭据不写入聊天消息。
4. “暂不配置”关闭卡片但保留草稿，再次提交可重新打开。切换会话时清除展示请求；归档或已有模型时不展示卡片。
5. 配置结果与任务提交结果分别显示；连接成功但绑定失败时提供重试入口。

## 当前边界

- 该切片只处理提交时缺少任务模型；其他设置类别的 Agent 主动提案仍未实现。
- 卡片与回执是前端状态，刷新后不会恢复提案历史；草稿继续提交依赖当前页面。
- 连接向导仍是分步注册与尽力回滚，不等同于原子配置事务。
- 本地联调模型只验证配置链路和任务提交，不代表真实大模型质量。

## 本地验收

隔离服务：`http://127.0.0.1:4410`，Runner `4411`。

1. 新建没有任务模型的会话；确认没有配置卡和重复配置提示，输入区可编辑。
2. 输入“请总结这项研究的主要发现”并点击“配置并继续”或按 Enter；应出现单张配置卡，原文仍在输入框，运行尚未创建。
3. 点击“暂不配置”；确认卡片消失、草稿保留。再次提交，应重新显示卡片。
4. 在卡片中选择已有模型或连接新模型并确认；确认当前会话绑定模型、原问题只提交一次，运行和回执可见，其他会话与全局默认模型不变。
5. 切换至另一会话，确认旧卡片不在新会话显示。
