# 对话内配置：首个真实接入切片 v4

本版依据 [交互设计 v4](conversational-settings.v4.md) 修正零模型首次接入，保留 [v3](conversational-settings-integration.v3.md) 的按需弹卡与手动入口。

## 零模型流程

卡片不显示空的模型选择，直接展示服务商连接向导，并说明首个模型会成为全局默认。向导验证连接后登记模型、设置默认值、保留其他全局设置；当前会话通过继承取得模型时不额外写会话覆盖。已有模型的卡片仍只绑定当前会话。

隔离服务 `4410` 预置了一个联调用模型且故意不设全局默认，以便测试“注册表有模型、会话缺模型”的分支。这是测试夹具，不是正常首次接入状态；其模型只用于验证配置链路，不代表真实模型质量。零模型流程通过组件和向导测试验证，不通过删除现有测试数据模拟。

## 当前边界

此切片仍只涵盖模型。已有可用全局默认时不会主动提出其他设置；连接器、Runner、权限及 API 适配器的 Agent 提案尚未接入。
