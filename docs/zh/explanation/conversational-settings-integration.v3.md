# 对话内配置：首个真实接入切片 v3

本版基于 [接入切片 v2](conversational-settings-integration.v2.md) 和 [交互设计 v3](conversational-settings.v3.md)，恢复输入框下方的手动配置入口。实现范围仍仅限缺少任务模型。

## 当前交互

1. 无模型会话初始显示一条轻量提示和“在对话中配置”按钮，不自动插入配置卡。已有模型时不显示提示。
2. 点击该按钮直接展开同一张配置卡；没有任务草稿时，确认模型只保存会话模型，不创建空任务。
3. 用户也可以先输入问题并提交；缺模型时暂停运行提交，显示配置卡，保留草稿，确认模型后通过原提交流程继续。
4. 配置卡打开时隐藏底部提示，避免同屏重复；选择“暂不配置”后提示恢复，草稿不丢失。会话切换后不显示旧卡片。

## 本地验收

在隔离服务 `http://127.0.0.1:4410` 打开无模型会话：先检查底部手动入口存在、上方卡片不存在；点击入口后检查只出现一张卡；关闭后检查入口恢复。输入非空问题后点击“配置并继续”或按 Enter，也应打开卡片并保留原问题。已有模型会话不应显示缺模型提示。
