# 对话内配置：明确连接器指令修复 v6

依据[交互设计 v6](conversational-settings.v6.md)，增加会话配置预检接口。它只识别完整的、目标唯一的连接器启用指令，目标必须来自已安装的 MCP 连接器目录；模型提供的任意名称、路径或 URL 不会变成配置写入。浏览器在提交对话前调用预检；返回 `proposal` 时展示现有确认卡片，不创建模型运行；返回 `not_applicable` 时继续原有模型流程。

预检复用 `connector_configuration_requests`、现有决定接口与会话范围配置写入。历史 `applied` 请求只作为审计记录；当前有效连接器集合决定是否仍需新的请求。待确认请求按会话和连接器去重，避免重复点击产生多张卡。确认仍由用户完成，应用时仍检查连接器状态及配置基线。
