四项已有能力继续保留：模型选择、模型连接、模型凭据修复、已就绪连接器启用。新增 `skill.select`、`thinking.configure`、`review.configure`，合计七项有限能力。P1 只向经过验证的 Native 后端开放，Skill 支持 Project/Session，思考与审阅支持 Session。

## 4. 本轮发现并修复的问题

1. **启动恢复越过激活阶段。** 旧恢复循环看到 applied companion 就直接恢复任务，导致通用请求尚未激活时被安全检查取消。现在通用记录只由持久激活/恢复阶段接管，旧入口也拒绝未激活的通用请求。
2. **重启版本误冲突。** 模型向 Provider 分组迁移和对象属性顺序不应使无关连接器批准失效。配置版本使用稳定表示；连接器只绑定相关资源，同时以私有 keyed transport 指纹和 OAuth 密文代际覆盖真正的认证/传输变化。
3. **Skill Library 静默升级。** 重新选择已继承的固定版本不会换成新 head，原 priority/limit 一并保留；新选择才固定获准版本。
4. **审阅设置影响旧任务。** automatic/level 现在随 run 入队冻结，产物沿明确执行来源关联。不同来源的审阅批次隔离；来源丢失失效收束，全局开关在异步准入后再次检查。
5. **拒绝后重复提案。** 同一任务的相同连接器需求不因无关模型/思考设置变化重新弹卡；相关基线变化或新的任务可以重新评估。
6. **卡片状态误导。** 等待配置的原任务显示“已暂停、等待选择”；已完成的纯 P1 配置显示“已保存、后续运行生效”。旧 30 秒授权入口仅在适用的历史请求中显示，v3 不显示无效的旧自动授权选项。
