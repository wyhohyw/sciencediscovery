# Desktop MCP settings UI v2

Actual desktop UI frames from code commit 19a991d08b197443037dae526ec507a16d0307b6, with deterministic fixture data. Creation, JSON prefilling and editing use one right-side configuration drawer.

English and Chinese frames cover the single Add menu, manual fields and validation, JSON source and prefilling, HTTP/STDIO/OAuth, details, editing, deletion and a smaller window. Main frames are 1920 × 1080 CSS pixels; the smaller frame is 768 × 720.

These frames supersede the earlier v1 create/import presentation. Original design inputs and runtime logs are excluded. SHA256SUMS records the PNG digests.
